# 🔍 GitHub Developer Analyzer

A web application that analyzes GitHub developer profiles and repositories using the GitHub REST API.

## ✨ Features
- 👤 GitHub profile analysis
- 📊 Repository & follower statistics
- 💻 Programming language analysis
- ⭐ Repository insights
- 📈 Interactive charts
- 🏆 Repository quality scoring
- 📱 Responsive UI

## 🛠️ Tech Stack

HTML • CSS • JavaScript • GitHub REST API • Chart.js
